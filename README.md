# go-treasury

기업 자금관리(트레저리)를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 운전자본과 13주 자금계획, 은행 차입과 약정, 자금 운용·자금 집중·결제, 금리·환율·원자재·거래처 신용 위험과 헤지, 외국환거래를 다룹니다. 한국 법·제도(외국환거래법·외국환거래규정, 자본시장법의 장외파생상품, 하도급법의 대금 지급, 채무자회생법 등)를 뼈대로 하고, 바젤 유동성 기준·미국·EU·일본 제도와 비교합니다. 자금 업무를 처음 배우는 사람도, 해 봤지만 체계가 없는 실무자·관리자도 대상입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 계산 과정을 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 공개 리포라 초대 없이 받을 수 있습니다. 터미널에서 `gh auth login`으로 한 번 로그인합니다. 시작하는 데 다른 설치는 필요 없습니다. 계산은 손 계산·계산기·스프레드시트 중 편한 것으로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-treasury
```

**Claude Code**

```bash
cd ~/Desktop/go-treasury
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-treasury` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 자금 업무 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 자금 업무가 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 계산은 내가 먼저 합니다.
4. 법 조문 번호나 신고 기준 금액·지급 기한처럼 바뀌는 내용은 튜터가 그 자리에서 국가법령정보센터 등 공식 출처를 확인하고 출처를 붙입니다. 오늘의 환율·금리는 공식 통계를 열었을 때만 말하고, 아니면 「가정」으로 계산합니다. 확인하지 못하면 못 했다고 말합니다.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준의 공식 출처와 조회일 |
| `learner/` | 내 기록, 내 HTML, 내 계산표. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 계산표를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다.

## 회사 자료와 자문

- 내 업무를 예로 들면 가장 잘 배웁니다. 다만 회사·거래처·은행 이름과 실제 잔액·한도는 가명·어림값으로 말해도 충분합니다. 튜터는 그런 이름이나 실제 수치를 웹 검색에 넣지 않지만, 대화 자체는 Claude 서비스로 전달됩니다. 여신 약정서·통장 사본 같은 원문은 이 폴더에 두지 말고, 계좌번호·인터넷뱅킹 정보는 대화에 넣지 마세요.
- 이 워크스페이스는 교육용입니다. 특정 금융상품·파생상품 가입이나 은행 선택을 권하지 않고, 헤지 비율 같은 회사별 수치를 정해 주지 않으며, 은행이 제시한 가격이 적정한지 판정하지 않습니다. 실제 외환 신고나 약정 해석은 거래 외국환은행, 한국은행 외환 신고 안내, 금융감독원, 법제처 법령해석, 전문가에게 확인하세요.

## 이웃 워크스페이스

투자결정·자본조달 수단 선택·헤지 여부의 결정은 go-finance, 헤지회계 같은 회계 기준은 go-accounting, 자금 집행 승인·직무 분리 같은 통제 설계와 전사 위험관리는 go-control, 예산·손익 포캐스트는 go-controllership, 무역 결제 서류·재고 운영은 go-scm, 해외직접투자 신고는 go-global-business, 세무는 go-tax에서 다룹니다. 여기서는 맞닿는 만큼만 다룹니다.
