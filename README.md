# go-finance

기업재무의 의사결정(투자결정·자본조달과 자본구조·배당과 자기주식·재무위험 감수 수준·세후 효과)을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 한국 법·제도(상법, 자본시장법, 법인세법 등)를 뼈대로 하고, 미국·EU·영국 등의 기준과 비교합니다. 재무를 처음 배우는 사람도, 업무로 해 봤지만 체계가 없는 실무자·관리자도 대상입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 계산 과정을 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 시작하는 데 다른 설치는 필요 없습니다. 계산은 손 계산·계산기·스프레드시트 중 편한 것으로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-finance
```

**Claude Code**

```bash
cd ~/Desktop/go-finance
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-finance` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 재무·자금 업무 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 재무가 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 계산은 내가 먼저 합니다.
4. 법 조문 번호나 금액 기준·세율처럼 바뀌는 내용은 튜터가 그 자리에서 국가법령정보센터 등 공식 출처를 확인하고 출처를 붙입니다. 확인하지 못하면 못 했다고 말합니다.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준의 공식 출처와 조회일 |
| `learner/` | 내 기록, 내 HTML, 내 계산표. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 계산표를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다.

## 회사 자료와 자문

- 내 업무를 예로 들면 가장 잘 배웁니다. 다만 회사 이름과 실제 금액은 가명·어림값으로 말해도 충분합니다. 튜터는 회사 이름이나 실제 수치를 웹 검색에 넣지 않지만, 대화 자체는 Claude 서비스로 전달됩니다. 계약서·통장 사본 같은 원문은 이 폴더에 두지 마세요.
- 이 워크스페이스는 교육용입니다. 투자 권유, 세무 신고, 법률 자문을 하지 않습니다. 실제 결정 전에는 법제처 법령해석, 금융위원회·금융감독원 질의회신, 국세청 예규, 전문가 확인을 거치세요.

## 이웃 워크스페이스

자금관리 실무(자금계획·은행·외환·헤지 실행)는 go-treasury, 회계 기준은 go-accounting, 기업가치평가는 go-valuation, 내부통제는 go-control에서 다룹니다. 여기서는 맞닿는 만큼만 다룹니다.
